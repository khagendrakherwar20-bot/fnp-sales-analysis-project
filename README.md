# Sales Analysis Project

## Project Overview
This project analyzes 2023 sales and order data to understand revenue performance, customer patterns, product categories, sales occasions, and delivery timelines. The goal is to turn raw order data into clear business insights that can support better sales and operational decisions.

## Objectives
- Analyze total revenue and order volume.
- Compare sales across occasions, product categories, and locations.
- Explore customer-level patterns where appropriate.
- Review order-to-delivery time and identify areas for operational improvement.
- Present findings in a clear, business-friendly report/dashboard.

## Tools
- **Microsoft Excel** — workbook, data review, pivot-table summaries, and reporting.

 
## Dataset
The workbook contains these main tables:

| Table | Records | Purpose |
|---|---:|---|
| `Orders` | 1,000 | Order date/time, customer and product IDs, quantity, occasion, location, delivery details, price, and revenue |
| `Customers` | 100 | Customer ID, name, city, contact details, gender, and address |
| `Products` | 70 | Product ID, product name, category, price, occasion, and description |
